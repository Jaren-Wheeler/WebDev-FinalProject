Our Python course was probably the simplest course we have done. It was a course used to build our foundations for other languages. Here we learned the basics of languages such as classes, functions, arrays, GUIS ect.

We have now taken 2 courses in web development. In the first course we learned the basics of HTML CSS and touched on JQuery bootstrap. here we learned the structure of HTML, how the DOM heiarchy works and how to add styling using CSS to ehance the visuals of the website. Our second course focused on JavaScript, JQuery and AJAX. Using these we learned how to create dynamic interactive websites using animations APIS and JavaScript

The java course focused on refining our skills learned in previous courses and helped deepen our knowledge in object oriented programming as this is the main focus in java. Everything in java is defined in a class and items inside the class are considered objects. Java is a good language for coding web applications and mobile applications so GUI is also an important part of java programming. For GUI we learned about Java Swing and how it is used to give a clean usable interface.

In C# we focused on coding window applications. We learned how to use Winforms, UPF and WPF. These window applications could be used to virtually anything but our main focus was mostly on things like calculators, forms and organizational apps. We also touched on databases and connecting them to your C# project

SQL was our first course that focused soley on databases. In this course we learned the ins and outs of databases using a few IDE's such as SQL Server and Oracle. We learned CRUD operations(Create, read, update and delete), procedures and functions which allow us to not write the same code over and over. We also got our hands on security, learning about permissions, how to name tables and columns. We also focused on how relational databases are supposed to relate to eacher and how to make the tables make sense using 1NF 2NF and 3NF
